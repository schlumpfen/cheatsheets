EDV-Glossar

Kurze Erläuterungen wichtiger IT-Begriffe (Elektronische Datenverarbeitung)

API – Programmierschnittstelle
Schnittstelle, über die Software-Komponenten miteinander kommunizieren. Eine API definiert, wie Funktionen aufgerufen werden, welche Daten erwartet und zurückgegeben werden und wie Fehler behandelt werden.
Backup – Datensicherung
Kopie von Daten, um sie vor Verlust zu schützen. Backups können lokal, auf externen Datenträgern oder in der Cloud erstellt und regelmäßig inkrementell oder differenziell aktualisiert werden.
Cloud Computing – Rechenleistung aus der Wolke
Bereitstellung von IT-Ressourcen wie Rechenleistung, Speicher oder Software über das Internet. Nutzer zahlen in der Regel nur, was sie verbrauchen, und können Ressourcen flexibel skalieren.
Datenbank – Strukturierte Datenspeicherung
System zur Speicherung und Verwaltung großer Datenmengen. Relationale Datenbanken nutzen Tabellen und SQL, während NoSQL-Varianten flexibelere Strukturen für Dokumente, Schlüssel-Wert-Paare oder Graphen bieten.
Deployment – Ausrollen von Software
Prozess, bei dem Anwendungen von der Entwicklungs- in die Produktionsumgebung übertragen werden. Automatisierte Pipelines (CI/CD) reduzieren Fehler und verkürzen die Zeit bis zur Bereitstellung.
Firewall – Netzwerkschutz
Sicherheitskomponente, die Netzwerkverkehr überwacht und unerlaubte Zugriffe blockiert. Es gibt Hardware- und Software-Firewalls sowie Next-Generation-Varianten mit Anwendungs- und Inhaltsfiltern.
Git – Versionsverwaltung
Verteiltes Versionskontrollsystem, das Änderungen an Dateien nachvollziehbar macht. Branches und Commits erleichtern parallele Entwicklung, Code-Reviews und die Zusammenarbeit in Teams.
Hardware – Physische IT-Komponenten
Physische Bestandteile von Computersystemen wie Prozessoren, Speicher, Netzwerkkarten oder Peripheriegeräte. Hardware bildet die Basis, auf der Software ausgeführt wird.
ISO/OSI-Modell – Netzwerk-Schichtenmodell
Referenzmodell für Netzwerkkommunikation mit sieben Schichten von der physischen Übertragung bis zur Anwendung. Hilft, Protokolle und Verantwortlichkeiten klar zu trennen.
LAN – Lokales Netzwerk
Netzwerk zur Verbindung von Geräten auf begrenzter Fläche wie Büro oder Heim. Nutzt meist Ethernet oder WLAN und ermöglicht hohen Datendurchsatz bei niedriger Latenz.
Open Source – Offene Software
Software, deren Quellcode öffentlich zugänglich ist und unter einer Lizenz steht, die Nutzung, Veränderung und Weitergabe erlaubt. Communities entwickeln gemeinsam und transparent.
Patch – Fehlerbehebung
Aktualisierung, die Fehler oder Sicherheitslücken schließt. Patches können einzelne Dateien betreffen oder als umfangreiche Service Packs ausgeliefert werden.
RAM – Arbeitsspeicher
Kurzzeitspeicher für Daten und Programme, die die CPU aktuell verarbeitet. Mehr RAM ermöglicht flüssigere Multitasking-Fähigkeiten und reduziert Auslagerung auf langsamere Datenträger.
SaaS – Software as a Service
Bereitstellungsmodell, bei dem Anwendungen über das Internet genutzt werden. Anbieter kümmern sich um Betrieb, Wartung und Updates, während Nutzer per Browser oder API zugreifen.
Ticket-System – Aufgabenverwaltung
Software zur Erfassung, Priorisierung und Nachverfolgung von Anfragen oder Störungen. Unterstützt Service-Teams beim strukturierten Arbeiten und beim Einhalten von SLAs.
Update – Aktualisierung
Paket, das neue Funktionen bringt oder Fehler behebt. Regelmäßige Updates halten Systeme sicher und aktuell; Automatisierung reduziert den manuellen Aufwand.
VPN – Virtuelles privates Netzwerk
Verschlüsselte Verbindung über ein öffentliches Netzwerk, die entfernte Standorte oder Nutzer sicher mit einem privaten Netzwerk verbindet. Schützt Daten vor Abhören und Manipulation.
Zwei-Faktor-Authentifizierung (2FA) – Zusätzliche Sicherheit
Anmeldeverfahren, das zwei unabhängige Nachweise verlangt (z. B. Passwort plus Einmalcode). Erhöht den Schutz vor unbefugtem Zugriff auch bei kompromittierten Passwörtern.
Nutzungshinweise: Die Begriffe sind kurz gehalten und sollen einen schnellen Überblick über gängige EDV-Konzepte geben. Die Inhalte können als Ausgangspunkt für Schulungen, Onboarding oder Projektdokumentation genutzt werden.
